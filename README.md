# 『영조실록』 民 용례와 문맥 판정 자료

배포일 2026년 11월 21일 · 판본 `min-context-2026-11-21-v1`

『영조실록』 원문에서 民이 나오는 위치와 그 문맥을 연구한 논문의 자료다. Ⅱ장의 분석 범위, Ⅲ장의 연구자·Codex 판정 비교, Ⅳ장의 신분 및 정책 사례를 확인할 수 있다. 이 판본은 2026년 11월 20일 승인 사항을 반영한 자료와 11월 21일 원고를 대조하여 작성하였다.

## 첫 용례에서 원문까지

CSV의 ‘일련번호’는 연구에서 부여한 식별자다. 제외 용례까지 연속해서 다시 번호를 매기지 않았다. ‘위치ID’는 기사의 XML 식별자와 본문 안에서 民이 나타난 위치를 결합한다. 기사ID를 `https://sillok.history.go.kr/id/` 뒤에 붙이면 원문을 열 수 있다. 일례로 일련번호 13과 14는 영조 즉위년 9월 22일 같은 하교에 등장한다. [『영조실록』 해당 기사](https://sillok.history.go.kr/id/wua_10009022_001)

원문 위치는 XML 기사 요소 level5 아래 text/content의 텍스트를 문서 순서대로 이은 뒤 양끝 공백을 제거한 문자열에서 센다. 첫 글자의 위치는 0이다. 본문 해시는 이 문자열을 UTF-8로 인코딩한 SHA-256이다. 원문의 위치를 찾으려면 XML의 표점과 공백을 그대로 사용한다.

## 판정 자료를 읽는 법

- Ⅱ장에서 센 단위는 民 한 글자가 나온 위치다. 3만 6725개 기사 중 3543개 기사에 7041곳이 있다. 적격 6833곳과 제외 208곳은 각각 별도 파일에 실었다. 적격 가운데 305개 기사의 617곳은 문맥 판정 기록이 있으며, 6216곳은 미독해다.
- ‘문맥판정기록’은 문맥을 읽어 기록을 남겼는지를, ‘항목확인용례’는 한 항목 이상을 확인했는지를 나타낸다. 후자는 303곳이다. ‘기존확인범위’와 ‘추가확인항목’을 함께 읽어야 연구자가 확인한 범위를 알 수 있다. 추가로 확인한 13·14·97·98은 과거 ‘미독해’였던 이력도 함께 보인다. 빈칸은 해당 열에 옮길 값이 없다는 뜻이다.
- 발언 주체와 현재 인용자를 따로 기록했다. 지칭 대상과 신분·논증 역할 열에는 미채택 제안이나 해석도 들어 있다. 신분별 확정 여부는 해당 항목의 근거와 채택 범위를 따른다. C01·C07·C08의 논증 역할은 논문에서 제시한 해석이다. 4276·4277은 두 신료의 발언을 비교한 사례다. 8월 15일 四民 구휼 기사는 시행 사실을 해석하는 데 썼으며, 그 기사의 미독해 용례에 새 판정을 부여하지 않았다.
- 과거 자료 204곳 중 203곳이 현재 적격이다. 과거에 저장한 귀속·기록 기능을 현재값과 대조하면 199곳이 같고 4곳이 다르다. 이미 기호를 정리한 과거 출력 열을 쓰면 200곳과 3곳이 된다. 6192의 ‘논평’이 과거 출력 단계에서 이미 C로 바뀌었기 때문이다.
- 새 30기사의 최초 판정 일치는 귀속 39/46, 기록 기능 30/36, 두 항목 모두 29/34다. 빈 비교값은 해당 항목의 분모에서 제외한 용례다. 11곳에서 적어도 한 항목의 최초 판정이 달랐다. 그중 9곳은 협의 뒤 Codex의 최초 값과 같아졌고, 정언섬의 두 용례는 연구자의 최초 값과 같았다. 협의 뒤 Codex 최초 값과 일치한 53/55는 별도의 비교다.
- 신분 관계 자료 120행 중 117행은 주집계, 3행은 결합어 전체에 관한 보조 기록이다. 같은 民에 복수 관계가 있을 수 있다. 판정 일치는 원문의 역사적 의미를 판별하는 도구의 정확도를 산출한 값이 아니다.

## 내려받기와 검증

이 판본의 [배포 페이지](https://github.com/chaeyoungjoo-eng/yeongjo-min-reproducibility/releases/tag/min-context-2026-11-21-v1)에서 `yeongjo-min-context-2026-11-21-v1.zip`을 내려받아 압축을 푼다. CSV는 UTF-8로 저장했고, 위치 번호와 기사 식별자를 보존하려면 해당 열을 텍스트로 불러오면 된다.

Python 3.10 이상에서 아래 명령으로 파일별 해시, 원고의 단계별 수치, 최초 판정 일치, 협의 뒤 값, 사례 연결을 확인할 수 있다. 추가 패키지는 필요하지 않다.

```text
python verify.py
```

국사편찬위원회 원문 XML 53파일이 있으면 다음 명령으로 각 民의 실제 글자와 본문 해시, 과거 재현 기록의 근거 구간까지 대조할 수 있다.

```text
python verify.py --xml-dir "원문 XML 폴더"
```

원자료는 국사편찬위원회의 『조선왕조실록』 원문 XML 중 『영조실록』이다. 연구에 사용한 원본의 파일명·크기·해시는 `source-xml.csv`에 실었다. 사료는 국사편찬위원회 조선왕조실록 누리집에서 기사 단위로 확인할 수 있다. 제3자 사료와 연구자의 파생 데이터는 출처를 구별하여 인용한다. [국사편찬위원회 조선왕조실록](https://sillok.history.go.kr/)
