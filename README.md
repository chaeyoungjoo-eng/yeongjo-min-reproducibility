# 영조실록 民 연구 재현 자료 — dev103c1

이 저장소는 『영조실록』 民 연구의 **비공개 준비 저장소**입니다. 공개 전환은 연구자가 별도로 결정합니다. 원고와 국문·영문 초록은 올리지 않습니다.

## 재현하는 범위

이 묶음은 **dev103c1의 판정값을 고정한 계산 재현**을 제공합니다. 36,725기사의 저장 원문, 民 7,041위치, 전체 배타 구간의 귀속·기능·마스킹 정보로 조건별 비교 7종과 기능 보류·귀속 보류의 범위 계산을 다시 수행합니다. 코드가 원문 한자 수와 인명·원주 제외를 다시 계산하고, 기대 결과와 대조합니다. 데이터에 남은 판정 근거와 보류 기록은 원문 대조에도 사용할 수 있습니다.

**원문 XML에서 모든 초기 판정값을 새로 만드는 전체 분류 프로그램은 아직 이 묶음에 포함하지 않았습니다.** 연구자의 판단을 컴퓨터가 독립적으로 재현했다거나 전체 원문을 독립 검증했다는 뜻도 아닙니다. 원문 추출·판정 규칙 구현까지 재실행하는 경로는 별도 보완 항목입니다. 두 범위는 [방법과 한계](docs/METHODS_AND_LIMITS.md)에 구별했습니다.

## 파일 받기

1. 저장소의 **Releases**를 누릅니다.
2. `dev103c1-repro-v1` 판본을 엽니다.
3. 첨부 파일 **yeongjo-min-dev103c1-repro-v1.zip**을 받습니다.
4. 받은 ZIP의 압축을 풉니다. 풀린 폴더 안에 `reproduce.py`, `data`, `expected`, `src`가 있는지 확인합니다.

배포 주소: https://github.com/chaeyoungjoo-eng/yeongjo-min-reproducibility/releases/tag/dev103c1-repro-v1

GitHub가 자동으로 붙이는 `Source code (zip)`에는 별도 배포 데이터가 들어 있지 않습니다. 위 이름의 전체 묶음을 받습니다. 저장소 Code에는 설명과 계산 코드, Releases 첨부에는 데이터까지 포함한 독립 묶음을 둡니다.

현재 Private 상태에서는 로그인한 저장소 소유자와 초대받은 계정만 접근할 수 있습니다. 심사자에게 주소만 보내면 열리는 상태가 아닙니다.

## 계산 실행

Python 3.10 이상이 필요합니다. 별도 패키지 설치와 Git 명령어는 필요하지 않습니다. Windows에서는 압축을 푼 폴더에서 터미널을 열고 다음 한 줄을 실행합니다.

```text
py -3 reproduce.py
```

macOS·Linux에서는 다음 명령을 사용합니다.

```text
python3 reproduce.py
```

성공하면 마지막 출력에 `"passed": true`가 나옵니다. `output/verification.json`에 검증 기록을, 같은 폴더의 JSON 파일들에 재계산 결과를 저장합니다. 실행할 때마다 데이터 파일의 SHA-256을 검사합니다. 입력 파일을 고쳤으면 원래 기대값과의 검증은 통과하지 않아야 합니다.
