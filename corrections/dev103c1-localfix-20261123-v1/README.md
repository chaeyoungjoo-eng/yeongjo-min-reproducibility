# dev103c1 국소정정 자료 v1 (2026-11-23)

이 자료는 dev103c1-repro-v1을 보존하면서 연구자가 채택한 다섯 구간의 정정과 빈도 비교의 변화를 재현한다. 전체 분류를 새로 생성하거나 전수 독해를 마친 자료가 아니다.

## 적용한 정정
- 영조 20년 8월 8일: 경기 감사에게 유시한 20자·民1곳을 O에서 K 직접 발화로 정정.
- 영조 22년 12월 27일: 諭御史書 안의 ‘民惟邦本, 本固邦寧’ 8자·民1곳을 비발화/U로 분리.
- 영조 28년 12월 18일, 30년 11월 20일: 명시적인 史臣曰 뒤 두 사론 본문을 C·기록서술로 정리. 기존 인명 제외를 유지한 집계 분량은 409자·95자, 합 504자이고 民은 없다. 전체 실록 사론의 분량이 아니다.
- 영조 22년 12월 27일: 仍謂璞曰 뒤 20자·民0곳을 귀속 보류에서 K 직접 발화로 정리.
각 구간의 시작·끝은 원래 저장 원문의 0부터 시작하는 반개구간 [시작,끝)이다. 원문·인명·원주 제외 조건과 다른 판정은 유지한다.

## 재현
1. [기존 배포판](https://github.com/chaeyoungjoo-eng/yeongjo-min-reproducibility/releases/tag/dev103c1-repro-v1)에서 yeongjo-min-dev103c1-repro-v1.zip을 받는다. 이 파일은 수정하거나 압축을 풀 필요가 없다.
2. 이 폴더의 파일들을 한 폴더에 받는다. 저장소 Code의 전체 ZIP을 받았다면 이 폴더로 이동한다.
3. 다음 명령을 실행한다. Python 3.10 이상, 별도 패키지 불필요.

    python reproduce_localfix.py 원래ZIP의전체경로

4. 기존 계층별 수치·7개 집계 조건·기본/확장 두 분자의 범위가 기존 기대값과 일치하는지 먼저 확인한다. 이어 정정을 각각·함께 반영한 8가지 결과를 계산하고, 채택한 ABCD 값과 기존값을 expected_impact_results.json과 대조한다.
5. 결과는 이 폴더의 output/에 저장한다. 입력 ZIP과 저장소의 기대값은 고치지 않는다.

source.json에는 기존 배포 파일의 이름·주소·SHA-256, patches.json에는 채택한 다섯 구간, target_ranges.json에는 원문 범위 확인값이 있다. expected_impact_results.json의 adopted가 모두 채택한 ABCD 값이다. 출력한 impact_results.json의 A·B·C·D 및 조합은 영향 분리용이다. derived에는 보류 분량·중복·전체 집계 범위도 함께 기록했다. 서로 다른 두 방식의 국소 차분 검수에서도 일치를 확인했다.

## 범위와 한계
최초 판정·기존 dev103c1·다른 연구의 자료를 덮어쓰지 않았다. 이번 검증은 네 기사 안의 다섯 구간에 한정한다. 다른 오류가 드물다는 근거나 독립적인 전체 정확도를 뜻하지 않는다. 문헌 인용의 분리는 지정한 원구절에만 적용한다. 사론 본문 안의 추가 인용 분리와 다른 사론의 재분류는 이번 정정에 포함하지 않았다.
