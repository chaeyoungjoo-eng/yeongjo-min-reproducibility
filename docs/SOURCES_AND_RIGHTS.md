# 사료 출처와 공개 상태

주 사료는 국사편찬위원회 조선왕조실록 누리집에서 제공하는 『영조실록』 원문이다.

https://sillok.history.go.kr/

기사 식별자(예: `wua_10511017_003`)와 각 본문의 SHA-256을 데이터에 보존했다. `data/source_xml_manifest.json`은 연구에 사용한 XML 53개 파일의 SHA-256과 기사 수를 기록한다. 이 묶음의 `articles.jsonl.gz`는 연구에 사용한 저장 원문 텍스트이며 원래 XML 파일 자체나 웹 화면의 레이아웃은 아니다. 원문 파일의 재직렬화·다른 내려받기 형식은 파일 해시가 다를 수 있다.

국역 전문, 선행 연구 PDF, 논문 HWPX, 국문·영문 초록, 로그인 정보, 전체 대화 기록, 컴퓨터의 개인 절대 경로는 배포 대상에서 제외했다. 원문 텍스트는 이 배포를 위해 새로 축약·윤문하지 않았다.

연구자의 지시에 따라 저장소와 고정 배포판을 열람 공개하였다. 별도의 포괄적 재이용 라이선스는 부여하지 않았다. 원자료의 권리와 연구 코드·파생 데이터의 이용 조건은 구별하며, 이 파일은 제3자 자료에 대한 재배포 허락을 확인했다는 선언이 아니다. 제3자 자료에 MIT·CC0 등 이용허락을 임의로 붙이지 않았다.

자료 인용에는 원자료의 출처와 실제 사용한 고정 판본을 함께 밝힌다. 원본 XML의 일괄 재취득 경로는 아직 이 묶음에 자동화하지 않았다.
