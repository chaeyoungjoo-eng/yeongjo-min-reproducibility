# 공개 상태와 남은 항목

연구자의 지시에 따라 저장소와 dev103c1-repro-v1 고정 배포판을 공개하였다. 로그인이나 계정 초대 없이 자료를 열람·내려받을 수 있다. 고정 ZIP, 데이터·판정값·계산 코드와 태그는 변경하지 않았다.

자료를 열람 공개한 일과 방법론의 모든 단계를 재현 가능하게 만든 일은 구별한다. 제공 범위는 최종 판정 데이터와 저장 원문을 이용한 계산 재현, 판정 근거·보류 검토 자료다.

남은 항목은 다음과 같다.

- 원자료·코드·파생 데이터의 재이용 조건과 정식 인용 정보를 더 구체적으로 기록한다. 현재 별도 포괄 라이선스를 부여하지 않았다.
- 최초 XML 추출부터 초기 판정 생성까지의 실행 경로와 새로운 독립 표본 평가는 별도 과제다. 공개 전환이 그 과제의 완료를 뜻하지 않는다.
- 논문에는 dev103c1-repro-v1과 고정 커밋 829329702c572c0dd0d3a8d1ea7aee890e5471dc를 명시한다.
- 영구 보관과 DOI 연결 여부는 별도로 검토한다.

고정 ZIP 안의 공개 준비 안내는 제작 당시의 상태를 기록한다. ZIP의 해시를 보존하기 위해 그 안내문을 소급 교체하지 않았으며, 현재 상태는 저장소 main의 README와 이 문서를 따른다.
