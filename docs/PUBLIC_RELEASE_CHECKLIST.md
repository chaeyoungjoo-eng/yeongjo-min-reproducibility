# 공개 전 남은 일

이 저장소는 비공개 준비본이다. 다음 항목의 완료를 선언하지 않는다.

1. 연구자가 공개 시점과 심사 중 접근 방식을 결정한다. 익명 심사 지침도 확인한다.
2. 원자료 재배포 범위와 코드·파생 데이터의 이용허락을 확인한다.
3. 논문과 저장소의 실제 저자 표기, 자료 제목, 배포일, 이용허락을 확정한다.
4. 초기 XML 추출·판정 생성 경로를 추가로 제공할지 결정하고, 제공하는 실행 범위를 정확히 적는다.
5. 다른 환경에서 ZIP만 받아 실행하는 시험을 확인하고, 제공하지 않은 원문 분류 재생성을 완료로 표현하지 않는다.
6. 논문의 데이터 판본 표기와 dev103c1 수치가 일치하는지 원고 수정 단계에서 확인한다. 이번 저장소 작업에서 원고는 수정하지 않는다.
7. 사용할 판본을 release/tag와 commit으로 고정한다. 영구 보관과 DOI 연결 여부도 검토한다.

GitHub에 파일을 올리는 일과 논문 방법론의 모든 단계를 재현 가능하게 만드는 일은 구별한다. 현재 제공한 것은 최종 판정 데이터와 원문을 이용한 계산 재현, 판정 근거·보류의 검토 자료다.
