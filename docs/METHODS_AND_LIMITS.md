# 재현 범위·판정 정보·검증 한계

## 이 배포본의 관찰 대상과 집계

관찰 대상은 『영조실록』 원문에 나타난 글자 民이다. 民이 없는 다른 백성 표현을 새 용례로 더하지 않는다. 본문 전체의 한자 문량도 함께 사용하며, 民이 없는 구간을 분모에서 빠뜨리지 않는다.

전체 36,725기사, 民 7,041위치를 수록한다. 분석 분모와 연결하는 위치는 6,855개다. 인명·원주 제외와 의미 판정은 서로 다른 필드로 구별한다. XML 인명과 원주를 같은 원칙으로 분자·분모에서 제외한다. 저장 원문, 각 본문의 SHA-256, 좌표, 배타 구간을 연결해 한자를 다시 센다.

주 비교 분자는 `primary_commoner_comparison is True`, 확장 분자는 `people_reference is True`다. 두 분자를 혼용하지 않는다. 비율은 선택한 분자 합을 같은 조건의 마스킹 후 한자 합으로 나누고 10,000을 곱한다. 영조와 신료에 같은 선택식을 적용하되 각각의 문량을 분모로 쓴다.

## 귀속과 기능

K는 현재 영조, R은 조선 왕실의 다른 인물과 인용된 선왕 등이다. 즉위 전 왕세제로서 한 영조의 말에는 발언 당시 지위 R을 적용한 지정 사례가 있다. O는 확인된 관원의 말이다. 외국 관원은 확인·채택한 기준 범위에서 O에 포함한다. P는 공초 맥락에 따른 귀속으로 실제 질문자의 개인 이름을 뜻하지 않는다. U는 기존 기준에서 별도로 확정한 기타 귀속이며 미판정과 다르다. 외국 군주도 채택한 지정 사례에 U를 적용했다. `null`은 보류를 나타낸다.

발언 주체와 말의 기능을 나누어 기록한다. 현장 발언, 문서 본문, 내부 인용, 문헌 근거, 간접 보고, 기록 서술을 한 층으로 합치지 않는다. 주 비교는 E가 K/O이고 갈래가 `발언·문서·인용·문헌 인용·비발화`에 속하면서 기능이 확정된 구간이다. 간접 보고는 별도로 남긴다. 실제 선택식은 코드의 `strict_primary`를 따른다.

자료에는 확정값, 기존 기준의 기계 대조값, 원문 대조 기록, 보류가 함께 있다. 모든 값을 연구자가 전수 독해해 판정했다는 뜻이 아니다. 노드의 `rule`, `evidence`, `source_status`와 정정 기록을 함께 읽는다. 모든 규칙 기호에 대응하는 초기 분류 프로그램의 이동 가능한 실행 경로는 아직 포함하지 않았다.

## 이번에 검증하는 것

- 제공한 저장 원문으로 한자 문량과 XML 인명·원주 마스킹의 집계를 재계산한다.
- 7,041위치와 배타 구간의 연결, 원문 본문 해시, 귀속·기능·갈래를 검사한다.
- 조건별 비교 7종의 기본·확장 분자와 분모, 연도별 분포, 보류 문량을 기존 dev103c1 결과와 대조한다.
- 귀속 확정·기능 보류 노드의 포함 여부에 따른 최저·최고와, 귀속 보류까지 넓힌 주변 외곽 범위를 재계산한다.
- 이 검사는 계산 재현이며 역사적 판정의 독립 정확도 평가가 아니다. 기존 현재100·추가38을 독립 평가로 제시하지 않는다.

## 남겨 둔 불확실성

기존 연구자 판단 20구간, 일부 공초의 내부 인용 종료, 박필순 질문 6자의 공초 P/별건 K 경계, `於我則曰白·於彼則曰黑`의 주어 해석을 자동으로 확정하지 않았다. 공초 질문자의 인명은 원문이 특정하지 않으면 비워 둔다. 실제 주체 정보와 P 같은 문맥 귀속을 구별한다.

귀속 확정 자료에서 기능 보류의 포함 여부만 바꾸면 영조의 밀도가 신료보다 높다. 귀속 보류까지 넓게 허용한 주변 외곽 범위로는 그 순서를 보증하지 못한다. 이 주변 범위는 같은 미귀속 자료를 서로 다르게 사용할 수 있어 동시에 실현되는 조합으로 해석하지 않는다. 신뢰구간이나 실제 역사적 역전의 증거가 아니다.

## 아직 보완할 재현 경로

원본 XML 53개에서 저장 원문을 추출하는 프로그램, 초기 분류 규칙과 모든 채택 판단 입력을 연결한 판정 생성 경로, 새로운 독립 표본 평가는 별도 과제다. 이 묶음의 성공을 그 세 과제의 완료로 표현하지 않는다. 논문의 “방법론 전체를 재현할 수 있다”는 서술은 실제 공개 범위를 넘어 쓰지 않는다.
